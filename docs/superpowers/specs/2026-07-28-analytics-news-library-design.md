## 1. 学迹 (Analytics)

**Route:** `/scholar/analytics`

### 1.1 统计卡片行
4 张卡片，与书院首页风格一致：本周学习时长、完成课程、学分、排名。每张带趋势箭头（↑/↓）。

### 1.2 学习热力图
近 12 周 GitHub 风格热力图，7 列 × 12 行。颜色从浅灰→深黑表示学习时长。底部图例。

### 1.3 双雷达图并排
- **左：课程分类雷达** — 伦理文化、数据科学、金融工程、战略思维、道家哲学 5 轴
- **右：能力雷达** — 理论理解、实践应用、批判思维、创新能力、团队协作 5 轴
- 使用 SVG polygon 绘制，Framer Motion 动画入场

### 1.4 S 型足迹时间线
近 20 条学习记录，日期和事件沿 S 型曲线排列：
- 用 CSS `position: absolute` 沿贝塞尔曲线路径排布节点
- 节点间用虚线连接，形成 S 型轨迹
- 最新记录在右下，最旧在左上
- 每个节点：日期 + 事件描述 + 图标
- 点击节点 → 展开详情（如跳转到对应课程）

### 1.5 钻取
点击雷达图某分类 → 展开该分类下已修课程 → 点击课程 → 典籍详情页

## 2. 院讯 (Academy News)

**Route:** `/scholar/news`

### 2.1 分类筛选
顶部标签组：[全部] [活动] [新课] [公告]

### 2.2 时间线 + 卡片
- 左侧竖线时间轴，按月份分段
- 每条一张横向卡片：封面图(100×70) + 分类标签(彩色) + 标题 + 摘要 + 日期
- 最新条目（7天内）带 "🆕" 标记
- 6 条 mock 数据

### 2.3 钻取
点击卡片 → 内联展开详情（完整图文），再点收起。不跳转。

## 3. 藏书阁 (Library)

**Route:** `/scholar/library`

### 3.1 双区布局
- **左侧 180px**：每日一句（顶部大字）+ 分类筛选标签 + 书籍列表
- **右侧**：章节目录 + 正文阅读区

### 3.2 每日一句
随机展示一条格言，如"学而时习之，不亦乐乎"、"知之为知之，不知为不知，是知也"。每次进入页面刷新。楷体大字。

### 3.3 书籍列表
8 本书，按分类筛选（全部/基金/保险/理财/经典）。每本一行：封面缩略图 + 书名 + 作者。

### 3.4 章节阅读
- 选中书籍 → 右侧显示章节目录（纵向列表）
- 点击章节 → 正文区显示该章节内容
- 底部有上一章/下一章导航
- 阅读进度存储在 localStorage

## 5. 样式规范

- 全黑文字 `#000`，中文楷体 + 英文/数字 Times New Roman
- 边框 `border-[#000]`，浅底 `bg-[#f7f7f7]`
- 圆角 `rounded-[14px]`（卡片）、`rounded-[10px]`（按钮）
- Framer Motion 入场动画 + hover 微动
- 雷达图 SVG stroke `#000`，fill 半透明 `rgba(0,0,0,0.08)`
- 热力图颜色梯度：`#fff` → `#e0e0e0` → `#c0c0c0` → `#808080` → `#404040` → `#000`
